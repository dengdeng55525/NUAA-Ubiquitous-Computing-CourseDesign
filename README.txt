2.智慧社区养老互助系统模拟平台设计
这个就是我用html写了一个简单的界面，表明我们对未来整体的系统长什么样子做一个模拟，由于实现相关逻辑判断都很简单没必要上前后端，这边一个前端就能全部搞定了。
