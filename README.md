# NUAA-Ubiquitous-Computing-CourseDesign

南京航空航天大学普适计算课程设计：智慧社区养老互助系统，包含养老互助任务调度及多方联动机制的 Flask 仿真平台、独立 HTML 演示页面和课程设计 PDF 报告。

## 项目内容

本项目围绕社区养老服务场景展开，将情境感知、任务调度、老人互助积分和应急救援联动组织为一个可交互的仿真系统。课程设计报告介绍整体系统方案，代码提供核心模块仿真与整体界面演示。

- **情境感知**：模拟老人心率、位置与跌倒异常，展示社区实时感知视图。
- **任务调度**：综合任务紧急度、老人风险和等待时间计算优先级，结合技能、距离和历史评分分配志愿者，显示任务进度。
- **互助网络**：模拟志愿者和互助老人参与服务，并根据服务时长、任务难度、服务质量和活跃度结算时间银行积分。
- **应急联动**：通过手动跌倒事件演示家属、社区与社会三级响应及紧急任务生成。
- **数据展示**：通过 Flask API 和 JavaScript 轮询展示任务、地图、积分榜、应急事件和决策日志。
- **整体界面演示**：独立 HTML 页面支持启动、暂停、添加紧急事件、重置系统和导出日志。

代码中的 PPO 调度部分采用特征评分模拟策略决策；当前仓库提供的是课程仿真实现。老人、志愿者和传感器数据在运行时随机生成，应急联动通过状态变化和日志演示。

## 运行环境

- Python 3（本次验证使用 Python 3.12）
- Flask、NumPy
- 现代浏览器

Flask 仿真页面通过 CDN 加载 Bootstrap 和 Font Awesome，独立 HTML 页面通过 CDN 加载 Font Awesome；完整显示样式和图标需要联网。

## 运行方式

### 养老互助任务调度及多方联动机制模块

在仓库根目录安装依赖，然后进入模块目录启动后端：

```bash
python -m pip install -r requirements.txt
cd "养老互助任务调度及多方联动机制模块设计"
python app.py
```

在浏览器中访问 [http://127.0.0.1:5000](http://127.0.0.1:5000)。页面由 Flask 渲染并连接 API，使用上述地址打开即可。

启动后初始化 10 位老人和 5 位志愿者，其中 2 位为互助老人。仿真以 600 倍速推进，前端每秒刷新一次数据；点击“模拟跌倒”可观察三级响应与紧急派单，后台决策日志同时输出到终端。数据保存在内存中，重启程序后重新初始化。

### 智慧社区养老互助系统整体演示

直接用浏览器打开根目录的 `智慧社区养老互助系统模拟平台设计.html`，使用页面上的“启动模拟”“暂停模拟”“添加紧急事件”“重置系统”和“导出日志”等按钮进行演示。

### 课程报告与辅助文件

- `162330318-丁俊泽-普适计算课程设计.pdf`：查看整体方案、模块设计与课程报告。
- `create_file_tree.py`：打印目录树，使用前需将脚本中的 `path_input` 改为本机目录。
